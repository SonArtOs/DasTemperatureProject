# Мониторинг волоконных сенсоров: температура (DTS) и виброакустика (DAS)

Учебный проект по анализу данных распределённых волоконных сенсоров.
Решает три задачи: прогноз температуры, классификация виброакустических
событий, детекция аномалий. Ключевая идея — объединение двух модальностей
(DAS + DTS) в одной модели.

## Результаты

| Задача                       | Модель           | Метрика       | Значение |
|------------------------------|------------------|---------------|----------|
| Прогноз температуры          | LSTM (DTS)       | MAE           | 0.048 °C |
| Прогноз температуры          | LSTM (DTS)       | RMSE          | 0.056 °C |
| Классификация событий        | CNN1D (DAS)      | macro F1      | 0.808    |
| Классификация событий        | Fusion (DAS+DTS) | macro F1      | 0.869    |
| Детекция аномалий            | Isolation Forest | аномалий      | 2 из 33  |
| Детекция аномалий            | Conv-AE          | аномалий      | 31 из 610|
| Бинарная классификация       | CatBoost         | accuracy      | 0.700    |
| Корреляция rms с событием    | point-biserial   | r             | +0.66    |

Ключевой вывод: fusion DAS+DTS улучшает macro F1 на +0.06 по сравнению
с одиночной CNN. Это подтверждает гипотезу о пользе мультимодальности.

## Идея проекта

Есть два типа сенсоров на одном волокне:

- DTS (Distributed Temperature Sensing) — температура вдоль волокна.
- DAS (Distributed Acoustic Sensing) — вибрации вдоль волокна.

Гипотеза: объединение двух модальностей даёт больше, чем каждая по отдельности.

- Только DAS: "это похоже на шаги".
- Только DTS: "температура падает".
- Fusion DAS+DTS: "шаги плюс падение температуры — вероятно, кто-то вошёл".

Это context-aware classification: классификация с учётом температурного контекста.

## Данные

DTS: 1633 точки вдоль волокна, 91 временной шаг (1 час).
После агрегации: 33 сегмента на 91 шаг.

DAS: 615 снимков вибрации, 50 сегментов по длине волокна.
Признаки: mean, std, max, min, rms, peak_factor, zcr,
энергии в 4 частотных полосах (0-10, 10-50, 50-200, 200-1000 Гц),
пространственный профиль по 50 сегментам.

## Модели

### LSTM: прогноз температуры

Модель видит все 33 сегмента волокна одновременно, учится на 12 предыдущих
шагах предсказывать среднюю температуру через 3 шага вперёд.

MAE = 0.048 °C, RMSE = 0.056 °C. Модель воспроизводит динамику,
а не выдаёт константу.

### CNN1D: классификация DAS

1D-свёрточная сеть на признаках DAS. Классы: фон, среднее событие, сильное
событие (пороги по rms: 70-й и 90-й перцентили).

macro F1 = 0.808. Основное усложнение — сильный дисбаланс классов (429/120/61).
Решено через RobustScaler, WeightedRandomSampler, FocalLoss.

### Fusion (DAS+DTS): классификация событий

DAS-ветка (1D-CNN) извлекает локальные признаки вибрации (вектор 32).
DTS-ветка (MLP) извлекает температурный контекст (вектор 8).
Векторы конкатенируются и подаются в общий классификатор.

macro F1 = 0.869 против 0.808 у одиночной CNN. Улучшение +0.06.

### Isolation Forest: детекция аномалий

Объединяет 5 DTS-признаков и 8 DAS-признаков (13 признаков).
contamination = 0.05, n_estimators = 200.
Найдено 2 аномальных сегмента из 33.

### Conv-AE: альтернативная детекция аномалий

Свёрточный автоэнкодер на DAS-признаках. Обучается восстанавливать
нормальные сигналы, помечает как аномалии те, где ошибка восстановления
высокая. Порог — 95-й перцентиль ошибок.
Найдено 31 аномальное окно из 610.

### CatBoost: бинарная классификация

Событие против фона. auto_class_weights = Balanced.
accuracy = 0.700, macro F1 = 0.697.

## Интерпретация результатов

### Корреляционный анализ (point-biserial)

| Признак    | Класс              | r      | p-value  |
|------------|--------------------|--------|----------|
| rms        | vib_and_temp       | +0.66  | 0.00003  |
| dts_delta  | vib_and_temp       | -0.46  | 0.007    |
| rms        | temp_rise_quiet    | -0.63  | 0.00008  |
| rms        | quiet              | -0.35  | 0.044    |

Вывод: rms — основной признак для детекции событий. dts_delta важен только
для класса с одновременным изменением температуры.

### Feature importance (CatBoost)

rms        82.0 %
dts_std    11.6 %
dts_slope   3.1 %
dts_delta   2.5 %
dts_mean    0.9 %

CatBoost подтверждает: для бинарной задачи "событие против фона"
вибрация важнее температуры.

## Ограничения

- Не определяем причины событий ("упало", "вошёл"). Это гипотезы,
  требующие разметки.
- Не классифицируем 6 типов одновременно: 33 примера недостаточно.
- Синхронизация DAS и DTS выполнена по индексу, а не по метке времени.
- Fusion использует дополнительные признаки (DTS), поэтому априори лучше
  одиночной CNN. Честное сравнение требовало бы CNN+DTS vs CNN без DTS
  на одинаковых данных.
